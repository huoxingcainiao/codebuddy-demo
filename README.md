# codebuddy-demo

A minimal demonstration repository created to validate the CodeBuddy GitHub connector.

## Purpose

- Verify that the GitHub connector can read repository contents.
- Verify that the GitHub connector can write repository contents.
- Provide a small, self-contained sample project with no external dependencies.
